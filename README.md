# Runeterra Campaign Field Guide

A responsive player-facing reference for the Runeterra Dungeons & Dragons campaign. Browse the current ancestries, search race or lineage names, and explore in-site class profiles for all 14 core classes. Class profiles summarize key features and level milestones; campaign-specific subclass details are reserved for future material.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

Race and class summaries are paraphrased from the campaign material and supplied 5e class references. They are a quick guide, not a replacement for complete rules text. Treat the DM's current campaign rules as authoritative when details change. The Piltover & Zaun masthead image is served locally from `public/cityscape.png`.
